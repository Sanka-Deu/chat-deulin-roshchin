# Чат – учебный проект

Простой веб-чат на Flask с регистрацией, авторизацией, обменом сообщениями в реальном времени (автообновление) и хранением истории в MySQL.

## Установка и запуск

### 1. Получить код

```bash
git clone <url-репозитория>
cd chat-deulin-roshchin
```
Или просто скачайте и распакуйте архив.

2. Создать виртуальное окружение
VS Code:
`Ctrl+Shift+P` → `Python: Create Environment` → `Venv`

Командная строка (Windows):

```bash
python -m venv venv
```
3. Активировать окружение
VS Code: окружение активируется автоматически. Если нет – выберите интерпретатор:
`Ctrl+Shift+P` → `Python: Select Interpreter` → выберите `venv`

Командная строка (Windows):

```bash
venc\Scripts\activate
```
4. Установить зависимости
```bash
pip install -r requirements.txt
```
requirements.txt:

```text
Flask==2.3.3
pymysql==1.1.0
Werkzeug==2.3.7
```
5. Настройка базы данных
По умолчанию используется удалённая MySQL. При необходимости измените параметры в `app.py` (функция `connect`).

Структура таблиц (минимально):

`users`: `id`, `name`, `surname`, `login`, `password` (`VARCHAR(255)`)

`messages`: `id`, `ownerId`, `deliverId`, `text`, `date` (`DATETIME`)

6. Запустить сервер
VS Code (терминал):

```bash
python app.py
```
Командная строка (Windows):

```bash
python app.py
```
7. Открыть чат
Перейдите в браузере: http://127.0.0.1:5000

Зарегистрируйтесь или войдите.

Слева – список пользователей.

Выберите собеседника и пишите сообщения – обновление происходит без перезагрузки страницы.

8. Остановить сервер
Нажмите `Ctrl + C` в терминале.

Возможные проблемы
Ошибка подключения к БД – проверьте доступность хоста и учётные данные.

Модуль `pymysql` не найден – переустановите: `pip install pymysql`
